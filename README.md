# MERN Job Portal

A full-stack **Job Portal Web Application** built with the **MERN Stack** that allows recruiters to post and manage jobs while users can apply for jobs and track their application status.

🔗 **Live Demo:**
https://job-portal-mern-stack-client-pied.vercel.app/

🔗 **GitHub Repository:**
https://github.com/Afnan-coder/job-portal-mern-stack

---

# Features

## User Features

* User authentication and secure login
* Browse available job listings
* Apply for jobs
* View applied jobs
* Track application status
* Upload resume

## Recruiter Features

* Recruiter authentication
* Recruiter Dashboard
* Post new job
* Manage posted jobs
* View job applications
* Manage applicants

# Installation

Clone the repository

```
git clone https://github.com/Afnan-coder/job-portal-mern-stack.git
```

Go to the project folder

```
cd job-portal-mern-stack
```

Install dependencies

```
npm install
```

Run the project

```
npm run dev
```

For backend
```
npm run server
```
